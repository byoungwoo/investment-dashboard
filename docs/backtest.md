# 분할매수 조건 검증 실험

이 실험은 매매 권고가 아니라 조건을 재현하는 오프라인 도구다. 앱의 점수 및 매매 표시는 변경하지 않는다.

기본 조건은 Opportunity >= 70, Trend Health >= 60, Trend가 5거래일 전보다 높음이다.
추세 개선은 5일 연속 상승을 뜻하지 않는다. 기준은 검증용 가정이며 사용자가 확정한 투자 규칙이 아니다.
종가로 판단한 신호는 다음 거래일 시가에 실행한다. 최초 자금의 1/3씩 최대 3회,
체결 간 최소 5거래일을 둔다. 매수 비용 기본값은 10bp(0.1%)이며 각 회차 예산에 포함한다.
매도·리밸런싱·현금 이자·세금·별도 배당 현금흐름·환율은 모델링하지 않는다.
가격은 Open/High/Low/Close 전체가 일관되게 조정된 자료여야 한다.

## 필요한 자료

- 가격 CSV: `Date,Open,High,Low,Close`. 최소 220거래일 이상의 준비 기간을 포함한다.
- 벤치마크 CSV: `Date,Close`. 종목과 같은 거래일 기준 자료.
- 밸류에이션 CSV: `Date,forwardPE,pegRatio`. PEG는 생략할 수 있다.
- Date는 시간대 없는 YYYY-MM-DD, 중복 없이 오름차순이다.

밸류에이션은 **해당 날짜 종가 시점에 이미 알려져 있던 값**이어야 한다.
현재 Yahoo info 응답을 과거 날짜에 붙이는 것은 금지한다. 이 앱은 과거 예상 PER/PEG를
저장해 오지 않았으므로 현재 저장소 자료만으로 완전한 전략 백테스트는 불가능하다.
입력 파일의 출처와 실제 관측 시점은 입력 제공자가 확인해야 한다.
누락 날짜는 채우지 않고 Opportunity=N/A, 매수 불가로 처리한다.
따라서 밸류에이션 없이 실행하면 Trend 추이만 확인할 수 있고, 거래 0회는 전략 성과가 아니다.

## 실행

```bash
python3 backtest.py --prices prices.csv --benchmark benchmark.csv \
  --valuations historical-valuations.csv --start 2026-01-01 \
  --output /private/tmp/portfolio-backtest-run
```

`--start` 이전 가격은 준비 기간에 사용하며 성과 집계에서는 제외한다.
평가 시작일 종가부터 신호를 사용하므로 최초 체결은 그 다음 거래일부터 가능하다.
출력 디렉터리는 새 경로여야 한다. signals.csv, trades.csv, equity.csv, summary.json을 저장한다.
`--help`에서 임계값, 개선 비교 기간, 분할 횟수, 매수 간격, 비용을 조정할 수 있다.

수익률은 미투자 현금을 포함한 최초 총자금 대비 수익률이다. 비교값은 같은 평가 기간
첫날 시가에 동일 종목을 전액 매수해 보유한 결과다. 최대 낙폭은 일별 종가 평가액 기준이며
장중 손실을 의미하지 않는다. 현재 보유 종목만 대상으로 한 결과에는 종목 선택 편향이 있다.
파라미터를 같은 기간에서 최적화하고 그 기간 수익률로 검증을 주장하지 않는다.
