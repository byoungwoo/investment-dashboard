# ADR-0005: 공시 스냅샷을 코드에서 분리하고 파일 스키마를 테스트로 강제한다

- 날짜: 2026-11-08
- 작성자: 이병우
- 상태: 유효
- 출처: 이 결정과 같은 커밋. 배경은 ADR-0003(스냅샷을 점수에서 분리)의 연장

## 맥락

`fundamentals.py` 가 363줄이었고 그 중 **182줄이 데이터**(IREN·AVGO·ABB·VRT 숫자),
나머지가 렌더 로직이었다. 두 가지 문제가 있었다.

1. **분기마다 숫자를 갈아끼우려면 파이썬 파일을 고쳐야 했다.** 커밋 diff가 코드 diff로 보여
   "어떤 숫자가 어떻게 바뀌었나"를 눈으로 좇아야 했다
2. **에이전트에게 맡길 수 없었다.** 숫자를 쓰려면 `show_fundamental_detail()` 과 같은 파일을
   편집해야 하고, 괄호 하나만 틀려도 상세 패널 전체가 죽는다

한편 `/earnings` 로 초안 작성을 자동화하려면 **쓰기 대상이 좁고 안전해야** 한다.

## 결정

1. 스냅샷을 `data/fundamentals/<TICKER>.json` 으로 분리한다. **파일명이 심볼이다** —
   파일 안에 심볼을 다시 적으면 둘이 어긋날 수 있다
2. `fundamentals.load_snapshots()` 가 디렉터리를 읽어 `FUNDAMENTAL_DETAILS` 를 만든다.
   이름을 유지했으므로 `app.py` 와 기존 테스트는 한 줄도 바뀌지 않았다
3. **스키마를 테스트로 강제한다** (`tests/test_fundamental_snapshots.py`):
   필수 키 13개, `source_url` 은 `https://`, `updated` 는 파싱 가능한 날짜,
   파일명은 `PORTFOLIO` 에 있는 심볼
4. `updated` 가 **100일**(분기 91일보다 김) 이상 지나면 상세 패널에 경고를 띄운다
   (`staleness_note()`). 화면이 조용히 과거를 보여주는 것을 막는다
5. 초안 작성은 `/earnings <티커>` 스킬이 하고 **커밋은 사람이 한다**

## 근거

- 데이터를 옮길 때 **손으로 옮겨 적지 않았다.** 기존 딕셔너리를 그대로 덤프해 JSON으로 쓰고,
  다시 읽은 값이 원본과 동일한지 비교했다. 옮기는 과정에서 숫자가 바뀌면 그게 최악이다
- 스키마 테스트는 변이 5종(`source_url` 삭제 / `updated` 를 `Q1 FY2027` 로 / `next_checks` 비움 /
  `status.tone` 삭제 / 오타 파일 `IRENN.json` 추가)을 심어 **전부 실패하는 것을 확인**했다
- "수치를 지어내지 않는다"는 지금까지 문서 규칙이었다. `source_url` 필수 검사가 그것을
  **커밋을 막는 장치**로 바꾼다 — 출처 없는 스냅샷은 테스트를 통과하지 못한다

## 검토한 대안과 기각 이유

- **딕셔너리를 그대로 두고 `/earnings` 가 `.py` 를 편집** — 에이전트가 렌더 로직과 한 파일을
  건드린다. 숫자 오류는 사람이 잡을 수 있지만 문법 오류는 패널을 죽인다. 기각
- **종목별 `.py` 모듈로 분리** — import 구조만 복잡해지고 스키마 검사는 그대로 어렵다. 기각
- **외부 DB / Supabase** — 분기에 한 번 바뀌는 4개 파일이다. git에 두면 변경 이력이 공짜로
  남고 PR에서 검토된다. 기각
- **발표 당일 자동 갱신** — 공시 숫자의 절반(백로그, ARR, 서술)은 표준 태그가 아니라
  보도자료 서술이고, badge 선택은 투자 해석이다. 사람 검토를 뺄 수 없다. 기각

## 결과

분기 작업이 "찾아서 정리"에서 "검토해서 승인"으로 바뀐다. 신선도는
`python3 scripts/snapshot_status.py --earnings` 로 한 줄에 확인한다.

되돌리려면 JSON 4개를 다시 `fundamentals.py` 딕셔너리로 붙이고 `load_snapshots()` 와
`tests/test_fundamental_snapshots.py` 를 지워야 한다. 그 순간 출처 검사도 함께 사라진다는
점을 먼저 판단해야 한다.
